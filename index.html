Projects

flowgate

Go · OpenTelemetry · Redis · MCP · Slack API · Prometheus · k6

Reliability gateway turned chaos lab. Token-bucket rate limiting, circuit breaker, and load shedding — then a fault-injection primitives library, an experiment framework with steady-state hypotheses and mandatory rollback, and an MCP server that lets AI agents run experiments inside server-enforced guardrails. All packages pass under Go's race detector. Modeled on real incidents: a directory-sync capacity stall and MPP stragglers.

Since extended with OpenTelemetry tracing (a span per request stage, with trace context carried from an agent through MCP tool calls), a Redis-backed rate limiter that replicas share (one atomic Lua script, tested against a real Redis), and a Slack slash command that verifies Slack's request signature and runs experiments through a multi-turn runner.

A k6 run against the live deployment (303,761 requests, ~2,025 req/s, p95 102 ms) found what a green unit suite could not: per-client limiting keyed on the connection address, which doesn't identify the client behind a reverse proxy. Written up as a postmortem; fixed, with regression tests, and the client-IP header is now trusted only when configured.

Deployed on Fly.io as a single process. The Redis-shared limiter, Slack front end and tracing run locally (docker compose, a tunnel, Jaeger) and in tests; a k6 before/after for the shared limiter is still to do.

llm-eval-harness

Python · pytest · OpenAI · Anthropic · ChromaDB · Streamlit · GitHub Actions

LLM evaluation harness with judge-based scoring (relevance, faithfulness, context sufficiency), adversarial and prompt-injection suites, tool-call and multi-agent validation, and a RAG extension scored on retrieval precision and adversarial retrieval. Drift detection gates CI — the build fails when metrics drift past expected values.

Multi-run variance surfaced a prompt-injection result in gpt-4o-mini that was unstable (0% across five runs) — invisible to a single pass. 41 test cases across 9 suites, 59 unit tests.

Built independently. Runs locally and in CI; not deployed as a service.
